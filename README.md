# Mobile Sales Dashboard using Power BI

## About Project

I created this Mobile Sales Dashboard using Microsoft Power BI.

In this project, I worked with mobile sales data and created an interactive dashboard to understand sales performance and find useful information from the data.

I used Power Query for data cleaning and transformation and Power BI for creating the dashboard and visualizations.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Excel

## What I Analyzed

In this project, I analyzed:

- Total Sales
- Total Quantity
- Total Transactions
- Average Sales
- Monthly Sales
- Brand-wise Sales
- Model-wise Sales
- Payment Method
- Customer Ratings
- Sales by Day

## Power BI Skills Used

- Data Cleaning
- Power Query
- Data Transformation
- Data Modeling
- DAX Measures
- Charts
- Cards
- Slicers
- Filters
- Dashboard Design

## Dashboard

The dashboard helps to easily understand mobile sales performance and compare different brands, models and other sales information.
